# Cold Read

Paste a cold email or DM. Jev reads it in under a second and tells you if it lands or gets archived.

## How it works

Runs entirely in your browser, on your own [Jev](https://typesafe.ai) API key. Nothing is stored — your key and message pass through a small relay just to get around browser CORS restrictions, then straight to TypeSafe's API and back.

Checks:
- **Personalized** — specific to the recipient, not a template fill
- **Clear ask** — one obvious, low-friction next step
- **Spam risk** — lower is better
- **Reason to reply now** — a real reason to answer soon
- **Fits that audience** (optional) — tell it who you're targeting, and it checks whether the copy actually speaks to them

## Get a Jev key

Early access at [typesafe.ai](https://typesafe.ai), then generate a key at [console.typesafe.ai/settings/keys](https://console.typesafe.ai/settings/keys).
